DSH Go **Root** @VERSION@ —— 个人 fork，含 root `shell` 工具。

- 已同步上游 ccch1mneyyy/dsh-Go main 到 **1.2.0**，运行时 1.2.0
- 不含内置 frida（代码、模块、打包步骤都已移除）
- 包名 `io.github.ouy09103.dsh_go_root`，应用名「DSH Go Root」，**可与原版同时安装**
- arm64 · Android 8.0（API 26）以上

**跟着上游 1.2.0 一起带来的**

- **手机操控确认改成三档**：允许一次、本轮允许、取消；设置里可以列一份「始终允许」的 App。
  停止只作用于当前这一轮，下一轮自动恢复。
- **酒馆。** 酒馆助手接口补齐，支持原生 MVU 变量；能把 DeepSeek 网页里聊不下去的对话导入酒馆接着聊，
  导入大卡和长聊天时明显不卡了。
- **让 AI 做一只宠物。** 带上自己的素材（GIF、逐帧图、Aseprite 导出或单张图），AI 把它转成宠物包。
- **按你问过的话搜索会话。** 会话搜索能搜到自己问过的话和回复摘要，句子中间的中文词也能搜到。
- **长回复更流畅。** 长回复分块显示，流式输出时只重排最后一块。
- 其他修复：安卓引擎在某些情况下重启被锁死；生成图片时网关返回空链接导致图片丢失；
  Windows 主机的盘符路径和链接打不开；回合结束但没有答复时没有任何提示；未发出的草稿丢失。

**这个 fork 自己的**

- **root `shell` 工具。** 原生侧 `dsh/root` 通道随引擎一起挂上，su 清单、申请授权、root 控制台都能用；
  设置里的 root 开关能开也能关（点开先确认，确认后写入并回读真实状态），快捷入口面板里也有一条。
- **设置 › MCP 对接。** 可登记外部 MCP 服务器（名字 + 地址 + 访问令牌），手机上保存后，
  引擎下次启动时带上。
- **更新只查本仓库。** 更新检查改成只认 `ouy09103-wq/dsh-Go` 的发布，
  不再读上游 `dl.dshtui.com` 那份（那是上游包名的 APK，装了也装不上）。

⚠️ 打开「启用 root」后，模型能以 root 身份执行任意命令。先备份，别装在主力机上。
