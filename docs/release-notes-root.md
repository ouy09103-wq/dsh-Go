DSH Go **Root** @VERSION@ —— 个人 fork，含 root `shell` 工具。

- 已同步上游 ccch1mneyyy/dsh-Go main，运行时 1.0.15
- 不含内置 frida（代码、模块、打包步骤都已移除）
- 包名 `io.github.ouy09103.dsh_go_root`，应用名「DSH Go Root」，**可与原版同时安装**
- arm64 · Android 8.0（API 26）以上

**这一版修的三件事**

- **「未检测到 su」修好了。** 原生侧 `dsh/root` 通道根本没有注册进引擎，
  于是页面只能读到空值；现在 `RootPlugin` 随引擎一起挂上，su 清单、申请授权、
  root 控制台都能用。su 探测也补了 PATH 兜底：有的 root 管理器不在固定路径放 `su`。
- **设置里的 root 开关能开也能关了。** 原来开关调的是反值（点开其实写的是关），
  而且被「Android Shell 通道可用」「手机操控总开关」两个无关状态卡住，现在只认
  root 授权本身：点开先确认，确认后写入并回读真实状态。
- **不聊天也能开到 root。** 快捷入口面板在没有打开会话时也多了一条 root 开关，
  和聊天页里那一条、设置里那一条是同一个值。

**另外**

- **更新只查本仓库。** 更新检查改成只认 `ouy09103-wq/dsh-Go` 的发布，
  不再读上游 `dl.dshtui.com` 那份（那是上游包名的 APK，装了也装不上）。

⚠️ 打开「启用 root」后，模型能以 root 身份执行任意命令。先备份，别装在主力机上。
